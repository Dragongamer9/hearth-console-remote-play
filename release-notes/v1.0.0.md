Hearth Console Remote Play 1.0, the first release.

- Play your own Xbox from anywhere: sign in with Microsoft in a window inside the app (Microsoft's own page), pick
  your console, wake it, and stream it.
- The stream decoded by the graphics card, with the delay always shown and a bar you can call up.
- Connection trouble explained in plain words, with what to try.
- A data limit counted on every network (20 GB a month, a warning at 90 %); data saver on a hotspot or always.
- Desktop and ROG Ally (Game Mode) layouts; hold View + Menu for 1 second for the app's menu.
- Cloud games as an optional tab.

Install it from the Hearth Store on Hearth OS, or download the AppImage below and run it. Needs testing with a real
Xbox.
